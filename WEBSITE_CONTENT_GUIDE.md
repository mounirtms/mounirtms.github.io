### General Questions

**Q: What is MAB Modules?**  
A: MAB Modules is a suite of 28 professional Magento 2 extensions designed specifically for the Algerian e-commerce market.

**Q: Which Magento version is supported?**  
A: MAB Modules supports Magento 2.4.x (both Open Source and Commerce editions).

**Q: Do you support Arabic language?**  
A: Currently, we offer complete French localization with Arabic support planned for future releases.

**Q: Can I purchase individual modules?**  
A: Yes! You can purchase any module individually or choose a package deal for better pricing.

### Technical Questions

**Q: How long does installation take?**  
A: Basic installation takes 30-60 minutes. Full configuration and testing typically takes 2-4 hours.

**Q: Do you offer installation services?**

**Q: What about updates?**  
A: All packages include free updates for the license period (6-24 months depending on tier).
